Educational Chatbot with Interactive Dashboard

Overview

This project is an AI-powered Educational Chatbot designed to provide interactive learning support to users. It answers questions, explains concepts, and enhances the learning experience using Natural Language Processing (NLP).

To make the project more user-friendly, it is integrated with Streamlit, which provides a clean and interactive web-based dashboard.

------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------

Features

Chatbot for answering educational queries

Supports multiple topics and concepts

NLP-based response system

Interactive dashboard using Streamlit

Fast and lightweight interface

Beginner-friendly project

-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------

Tech Stack

Programming Language: Python

Libraries Used:

Pandas

NumPy

Scikit-learn / NLP libraries

Frontend: Streamlit

Backend Logic: Python
